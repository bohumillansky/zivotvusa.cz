# Facebook artwork

Created with the built-in image generation tool for the Život v USA Facebook page.

- `profile.png`: square Rocky Mountain travel emblem with a red sun and the text `USA`, navy/cream/red palette, composed for a circular avatar crop.
- `cover.png`: panoramic Colorado/Flatirons landscape with an open road, pine foothills and a distant town; exact text `Život v USA` and `Americké zkušenosti očima Čecha`, matching the avatar palette.

Prompt set: polished editorial travel poster illustrations with subtle paper texture, bold simplified shapes, welcoming mood, no people, flags, watermarks or mockups. Keep important avatar details inside the circular crop; keep cover text and landscape readable in Facebook's horizontal crop.

Both images were uploaded as the Page's profile picture and cover photo. No paid promotion was enabled.
